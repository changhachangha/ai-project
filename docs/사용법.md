# AI-Project 사용 가이드

개발 중에 자주 쓰는 도구 47개를 한곳에 모아 둔 웹사이트입니다. 설치나 회원가입 없이 브라우저에서 바로 쓸 수 있습니다.

이 문서는 **사이트를 쓰는 방법**만 다룹니다. 개발 환경 구축이나 코드 구조는 [README](../README.md)를 참고하세요.

## 1. 화면 구성

화면은 세 영역으로 나뉩니다.

| 영역 | 위치 | 역할 |
| --- | --- | --- |
| 사이드바 | 왼쪽 | 카테고리별 도구 목록. 모바일에서는 숨겨집니다. |
| 헤더 | 상단 | 테마 전환, 홈으로 돌아가기 |
| 본문 | 가운데 | 홈에서는 도구 목록, 도구 페이지에서는 입력·결과 화면 |

홈(`/`)은 사이트의 중심입니다. 추천 도구, 검색, 정렬, 전체 목록이 모두 여기에 있습니다.

## 2. 도구 찾기

찾는 방법은 네 가지입니다. 상황에 맞는 것을 쓰면 됩니다.

### 검색창으로 찾기

홈 상단 검색창에 입력하면 **도구 이름과 설명**을 함께 검색합니다. 결과는 입력하는 즉시 좁혀집니다.

### 단축키로 찾기

어느 페이지에서든 <kbd>Ctrl</kbd>+<kbd>K</kbd>(macOS는 <kbd>⌘</kbd>+<kbd>K</kbd>)를 누르면 도구 검색 창이 열립니다. 검색어를 넣고 항목을 클릭하면 해당 도구로 바로 이동합니다.

### 사이드바로 찾기

사이드바는 카테고리별로 접혀 있습니다.

1. 카테고리 이름을 클릭해 펼칩니다.
2. 목록에서 도구를 클릭합니다.
3. 모바일에서는 이동과 동시에 사이드바가 닫힙니다.

현재 보고 있는 도구가 속한 카테고리는 자동으로 펼쳐집니다.

### 목록 정렬로 찾기

홈 오른쪽의 정렬 메뉴에서 기준을 고릅니다.

| 정렬 기준 | 순서 |
| --- | --- |
| Name (A-Z) | 이름 오름차순 (기본값) |
| Name (Z-A) | 이름 내림차순 |
| Category | 카테고리별 묶음 |

목록은 한 페이지에 30개씩 표시되며, 아래 페이지 번호로 넘깁니다.

### 카테고리 한눈에 보기

| 카테고리 | 도구 수 | 예시 |
| --- | --- | --- |
| 인코딩 | 10 | Base64, Hex, URL, Morse 코드 |
| 변환 | 9 | 색상, 단위, 타임스탬프, QR 코드 |
| 텍스트 | 15 | JSON 포매터, Diff, 정규식, 케이스 변환 |
| 보안 | 8 | 해시, AES, JWT, TOTP, RSA 키 |
| 개발자 | 5 | API 테스터, Cron, 네트워크 도구 |

## 3. 도구 사용하기

대부분의 도구는 같은 흐름을 따릅니다.

1. **입력합니다.** 텍스트를 직접 입력하거나, 파일 업로드 버튼으로 파일을 불러옵니다.
2. **실행합니다.** 실행 버튼을 누릅니다. 일부 도구는 입력과 동시에 결과가 갱신됩니다.
3. **결과를 가져갑니다.** 복사 버튼으로 클립보드에 담거나, 다운로드 버튼으로 파일로 저장합니다.

도구마다 다른 부분은 다음과 같습니다.

- **모드 전환** — Base64처럼 인코딩·디코딩을 오가는 도구는 상단 버튼으로 모드를 바꿉니다. 모드에 따라 입력창 안내 문구가 함께 바뀝니다.
- **파일 입력** — 파일 업로드를 지원하는 도구는 텍스트 대신 파일을 넣을 수 있습니다.
- **실시간 계산** — 해시·타임스탬프처럼 입력 즉시 결과가 나오는 도구는 별도 실행 버튼이 없습니다.
- **초기화** — 입력과 결과를 한 번에 비웁니다.

결과 영역은 읽기 전용입니다. 값을 고치려면 입력창을 수정한 뒤 다시 실행하세요.

## 4. 즐겨찾기

자주 쓰는 도구를 따로 모아 둘 수 있습니다.

1. 홈 목록에서 도구 카드의 **하트 아이콘**을 클릭합니다.
2. 상단 **Favorites** 탭으로 전환하면 담아 둔 도구만 보입니다.
3. 같은 하트를 다시 누르면 목록에서 빠집니다.

즐겨찾기는 **브라우저에 저장**됩니다. 따라서 서버 계정과 무관하고, 브라우저나 기기를 바꾸면 따라가지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다.

## 5. 화면 설정

### 테마 바꾸기

두 곳에서 바꿀 수 있습니다.

- **헤더 오른쪽 아이콘** — 라이트·다크를 빠르게 전환합니다.
- **설정 페이지**(`/settings`) — 라이트, 다크, 시스템 설정 중에서 고릅니다.

'시스템 설정'을 고르면 운영체제의 다크 모드 설정을 따릅니다. 선택한 테마는 브라우저에 저장되어 다음 방문에도 유지됩니다.

### 사이드바 접기

데스크톱에서는 사이드바가 항상 보입니다. 화면이 좁아지면 자동으로 숨겨지고, 헤더 왼쪽의 메뉴 버튼으로 다시 엽니다.

## 6. 모바일에서 사용하기

모바일에서는 사이드바가 기본으로 닫혀 있습니다.

- **도구 목록 열기** — 헤더 왼쪽의 메뉴 버튼
- **홈으로 돌아가기** — 헤더 왼쪽의 뒤로 가기 버튼
- **도구 이동** — 사이드바에서 도구를 고르면 자동으로 닫히고 해당 페이지로 이동합니다

입력창과 결과창은 화면 너비에 맞춰 세로로 쌓입니다. 긴 결과는 스크롤해서 확인하세요.

## 8. 자주 묻는 질문

**입력한 내용이 서버로 전송되나요?**
대부분 전송되지 않습니다. 도구 대부분이 브라우저 안에서만 계산합니다. 예외는 Diff 도구로, 비교 연산만 서버(`/api/diff`)에서 처리합니다. 비밀번호·개인키처럼 민감한 값을 다루는 도구는 모두 브라우저에서 계산합니다.

**회원가입이 필요한가요?**
필요 없습니다. 즐겨찾기와 테마는 브라우저에 저장되므로 계정이 없습니다.

**즐겨찾기가 사라졌어요.**
브라우저 저장소를 지웠거나, 시크릿 모드로 열었거나, 다른 브라우저·기기를 쓰고 있을 수 있습니다. 즐겨찾기는 기기별로 따로 관리됩니다.

**폰트 크기와 날짜 형식 설정이 안 먹혀요.**
설정 페이지에 항목은 있지만 아직 동작하지 않습니다. 현재 실제로 적용되는 설정은 **테마**뿐입니다.

**도구 페이지에서 404가 떠요.**
주소를 직접 입력했다면 경로가 맞는지 확인하세요. 경로는 `/{카테고리}/{도구-id}` 형식입니다(예: `/text/case-converter`). 홈이나 사이드바를 거쳐 들어가면 잘못된 경로로 갈 일이 없습니다.

**결과가 예상과 달라요.**
도구별 입력 형식을 확인하세요. 예를 들어 해시 검증은 알고리즘별로 기대하는 문자열 길이가 다르고, Diff 도구는 비교 모드(글자·단어·줄)에 따라 결과가 달라집니다.
